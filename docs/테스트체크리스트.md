## 핵심 시나리오 요약

### 인증
- [ ] 이메일/비밀번호 회원가입 및 로그인
- [ ] Google 소셜 로그인
- [ ] Access Token 만료 시 Refresh Token으로 자동 갱신
- [ ] 로그아웃 후 보호 API 접근 차단

### 게시글·댓글
- [ ] 게시글 작성 (이미지 첨부 포함)
- [ ] 게시글 목록 조회 (카테고리·검색·정렬)
- [ ] 댓글·대댓글 작성 및 삭제
- [ ] 좋아요 토글 (게시글·댓글)
- [ ] 비회원 게시글·댓글 조회 가능 여부 확인

### 마이페이지
- [ ] 닉네임·프로필 이미지 변경
- [ ] 내 게시글 목록 조회
- [ ] 레이아웃 변경 (구독자 전용 UI 확인)
- [ ] 결제 내역 조회

### 공개 프로필
- [ ] 비회원에서 타 유저 프로필·게시글·반려동물 조회
- [ ] 비회원에서 메인 인기 펫 피드 조회

### 구독·결제
- [ ] 정기결제 구독 (카드 등록 → 1회차 결제 → ACTIVE)
- [ ] 단건 구매 (1개월 이용권 → ACTIVE)
- [ ] 구독 해지 (ACTIVE → 만료일 도달 → EXPIRED)
- [ ] 결제 실패 시 PAST_DUE 전환 및 혜택 차단
- [ ] PortOne 웹훅 환불 → 즉시 EXPIRED

### 반려동물 (구독자 전용)
- [ ] 반려동물 등록 (비구독자 403 확인)
- [ ] 펫 사진 업로드 및 좋아요
- [ ] 인기 펫 사진 피드 (비회원 접근 가능 확인)

### 알림
- [ ] Web Push 구독 등록
- [ ] 알림 수신 및 GNB 드롭다운 표시

### 관리자
- [ ] `/admin` 비관리자 접근 차단 (403)
- [ ] 회원 목록 조회 및 권한 변경
- [ ] 게시글 강제 삭제
