## 화면 목록 및 화면↔API 매핑

| 화면 ID | 화면 이름 | 경로 | 주요 API |
|---------|-----------|------|----------|
| S-01 | 메인 | `/` | `GET /pets/photos/popular`, `GET /posts?sort=viewCount` |
| S-02 | 로그인·회원가입 | `/login` | `POST /auth/login`, `POST /auth/signup` |
| S-03 | OAuth 콜백 | `/oauth/callback` | `POST /auth/oauth2/exchange` |
| S-04 | 게시글 목록 | `/posts` | `GET /posts` |
| S-05 | 게시글 상세 | `/posts/:id` | `GET /posts/:id`, `GET /posts/:id/comments`, `POST /posts/:id/likes` |
| S-06 | 게시글 작성·수정 | `/posts/new`, `/posts/:id/edit` | `POST /posts`, `PUT /posts/:id`, `POST /images/upload` |
| S-07 | 마이페이지 — 프로필 | `/mypage` | `GET /users/me`, `PATCH /users/me/nickname`, `PATCH /users/me/profile-image` |
| S-08 | 마이페이지 — 내 게시글 | `/mypage` (posts 탭) | `GET /users/me/posts`, `PATCH /users/me/profile-layout` |
| S-09 | 마이페이지 — 반려동물 | `/mypage` (pets 탭) | `POST /pets`, `POST /pets/:id/photos`, `POST /pets/:petId/photos/:photoId/like` |
| S-10 | 마이페이지 — 구독·결제 | `/mypage` (payment 탭) | `GET /subscriptions/me`, `GET /payments` |
| S-11 | 구독 결제 | `/subscription` | `POST /billing-keys/prepare`, `POST /billing-keys`, `POST /subscriptions`, `POST /subscriptions/one-time/prepare`, `POST /subscriptions/one-time/complete` |
| S-12 | 공개 프로필 | `/users/:id` | `GET /users/:id`, `GET /users/:id/posts`, `GET /users/:id/pets`, `GET /pets/:id/photos` |
| S-13 | 관리자 | `/admin` | `GET /admin/users`, `GET /admin/statistics/daily`, `GET /admin/subscriptions`, `GET /admin/payments` |
