## 프로젝트 한 줄 목표
반려동물 집사들이 Q&A·자랑 게시글로 지식을 공유하고, 구독을 통해 반려동물 프로필·피드를 이용하는 커뮤니티 플랫폼

## MVP1 요약
- 회원가입·로그인(JWT), Google 소셜 로그인(OAuth2 OIDC)
- 게시글 CRUD(Q&A·BOAST), 이미지 다중 첨부(최대 5장), 댓글·대댓글
- 게시글·댓글 좋아요, 비로그인 게시글 조회
- 마이페이지(프로필 이미지·닉네임 변경, 내 게시글 목록)
- 공개 프로필(타 유저 게시글 조회, 비회원 공개)
- ADMIN: 회원·게시글 관리, 일일 통계
- 핵심 사용자: GUEST(비로그인) · USER · ADMIN
- 완료 기준: 로그인 → 게시글 작성·댓글·좋아요까지 시연 가능

## MVP2 확장 요약
- PortOne 구독 결제(정기 월 1,900원·단건), 결제 내역(PAID·FAILED)
- 반려동물 프로필·사진 업로드·좋아요 (구독자 전용)
- 인기 펫 사진 메인 노출(비회원 공개), LIST/GRID 레이아웃 전환(구독자)
- Web Push 알림(VAPID), GNB 알림 드롭다운
- 발표 시연 포인트: 로그인 → 게시글 → 구독 결제 → 마이페이지(펫 등록) → 공개 프로필 → 알림
