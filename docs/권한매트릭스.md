# 권한 매트릭스

## 원본
- Notion: https://app.notion.com/p/3b173873401a8000a209ede87caed059

## 역할 정의

| 역할 | 설명 |
|------|------|
| GUEST | 비로그인 사용자 |
| USER | 로그인 사용자 |
| SUBSCRIBER | 구독(결제) 완료 USER (status=ACTIVE) |
| ADMIN | 관리자 |

## API × 역할 매트릭스

| API | GUEST | USER | SUBSCRIBER | ADMIN |
|-----|-------|------|------------|-------|
| `GET /posts`, `GET /posts/:id` | ✅ | ✅ | ✅ | ✅ |
| `POST /posts` | 401 | ✅ | ✅ | ✅ |
| `PUT/DELETE /posts/:id` (본인) | 401 | ✅ | ✅ | ✅ |
| `DELETE /posts/:id` (타인) | 401 | 403 | 403 | ✅ |
| `GET /posts/:id/comments` | ✅ | ✅ | ✅ | ✅ |
| `POST /comments` | 401 | ✅ | ✅ | ✅ |
| `PUT/DELETE /comments/:id` (본인) | 401 | ✅ | ✅ | ✅ |
| `POST /posts/:id/likes` | 401 | ✅ | ✅ | ✅ |
| `GET /users/me` | 401 | ✅ | ✅ | ✅ |
| `PATCH /users/me/nickname` | 401 | ✅ | ✅ | ✅ |
| `PATCH /users/me/profile-layout` | 401 | ✅* | ✅ | ✅ |
| `GET /users/:id`, `GET /users/:id/posts` | ✅ | ✅ | ✅ | ✅ |
| `GET /users/:id/pets`, `GET /pets/:id/photos` | ✅ | ✅ | ✅ | ✅ |
| `POST /pets` (반려동물 등록) | 401 | 403 | ✅ | ✅ |
| `POST /pets/:id/photos` | 401 | 403 | ✅ | ✅ |
| `GET /pets/photos/popular` | ✅ | ✅ | ✅ | ✅ |
| `POST /subscription/recurring` | 401 | ✅ | ✅ | ✅ |
| `GET /payments/history` | 401 | ✅ | ✅ | ✅ |
| `GET /admin/**` | 401 | 403 | 403 | ✅ |

> `*` 레이아웃 API 호출은 가능하나, 프론트에서 SUBSCRIBER만 토글 UI 노출
