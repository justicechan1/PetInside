# 배포 가이드

## 인프라 구성

| 구성 요소 | 사용 기술 |
|-----------|-----------|
| 서버 | AWS EC2 (Amazon Linux 2023) |
| 도메인 | nip.io (`15-164-213-118.nip.io`) |
| 리버스 프록시 | Nginx |
| SSL | Let's Encrypt (Certbot) |
| 백엔드 런타임 | Java 17 (Corretto), systemd 서비스 |
| 프론트 정적 파일 | Nginx `/app/frontend/` |
| DB | MySQL (EC2 내 로컬) |

## CI/CD (GitHub Actions)

### 백엔드 (`deploy-backend.yml`)
- **트리거**: `develop` 브랜치 `backend/**` 경로 push (또는 수동 dispatch)
- **빌드**: Gradle `bootJar -x test` (JDK 17 Corretto)
- **배포**:
  1. SCP로 JAR 파일 EC2 `/app/backend/app.jar` 업로드
  2. SSH로 `/app/backend/.env` 갱신 (GitHub Secrets → 환경변수 주입)
  3. `sudo systemctl restart petinside-backend`

### 프론트엔드 (`deploy-frontend.yml`)
- **트리거**: `develop` 브랜치 `frontend/**` 경로 push (또는 수동 dispatch)
- **빌드**: `npm ci` + `VITE_API_URL=https://<EC2_HOST> npm run build`
- **배포**:
  1. `frontend/dist/` → EC2 `/app/frontend/` SCP
  2. `sudo chown -R nginx:nginx /app/frontend`
  3. `sudo systemctl reload nginx`

## GitHub Secrets 목록

| Secret 명 | 용도 |
|-----------|------|
| `EC2_KEY` | EC2 SSH 접속 PEM 키 |
| `EC2_HOST` | EC2 퍼블릭 IP (`15-164-213-118.nip.io`) |
| `DB_USERNAME` / `DB_PASSWORD` | MySQL 접속 정보 |
| `JWT_SECRET` | JWT 서명 시크릿 |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` / `GOOGLE_REDIRECT_URI` | Google OAuth2 |
| `OAUTH2_REDIRECT_URI` | OAuth2 콜백 프론트 URL |
| `CORS_ALLOWED_ORIGINS` | CORS 허용 origin |
| `PORTONE_STORE_ID` / `PORTONE_CHANNEL_KEY` / `PORTONE_CHANNEL_KEY_SUBSCRIPTION` | PortOne 결제 |
| `PORTONE_API_SECRET` / `PORTONE_WEBHOOK_SECRET` | PortOne API 인증·웹훅 |
| `BILLING_KEY_ENCRYPTION_SECRET` | 빌링키 AES 암호화 |
| `PORTONE_WEBHOOK_NOTICE_URL` | 웹훅 수신 URL (하드코딩) |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | Web Push 알림 |

## EC2 서비스 구성

백엔드는 systemd로 관리:
```
/etc/systemd/system/petinside-backend.service
ExecStart=java -jar /app/backend/app.jar
EnvironmentFile=/app/backend/.env
```

Nginx 설정: HTTPS 종단 + `/api/` 요청 → `localhost:8080` 프록시, 나머지 → `/app/frontend/` 정적 서빙
